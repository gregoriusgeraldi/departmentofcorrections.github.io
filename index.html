Response Codes

  • Code 1 — Non-emergency
  • Code 2 — Lights only
  • Code 3 — Lights & Sirens
  • Code 4 — Situation under control
  • Code 6 — Investigating on foot
  • Code 7 — Meal Break

How to Use 10-Codes / Response Codes on Radio

Escorting Prisoners to Bolingbroke

Dispatch, 41-Bravo-151 76 to bb escorting 5 95 eta 10 Min, Standby Future Update

Initial Reporting

Dispatch, Adam-20 would be doing 10-55 situation on [nama jalan], 10-60 gonna be [deskripsi kendaraan] with [jumlah penumpang] occupants inside. Standby for future updates.

Updating the Situation

Dispatch, for the last 10-55 situation on [nama jalan], it's now changing into active 10-57 (pursuit). Requesting 10-78 (backup) on my 20 (location). Suspect is now heading [arah pelarian].

Detailed Callout Example

Suspect is now heading West on Vespucci Blvd, taking left on intersection, heading South on San Andreas Ave.

Preferred Update Structure

  • Action — heading / belok kiri / belok kanan
  • Direction — North / South / East / West
  • Street Name — lokasi atau jalur
  • Additional Information — landmark, lalu lintas, deskripsi suspect
Heading West on Vespucci Blvd, taking left at intersection, heading South on San Andreas Ave. Light traffic, occupied by 2 suspects.

Incident Commander

Seorang IC harus tegas, sigap, menguasai situasi, berani mengambil keputusan, dan tidak takut menegur. IC bukan sekadar role, tapi tanggung jawab penuh atas jalannya sebuah insiden.
